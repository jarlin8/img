A Hybrid magazine/shop/review/news WordPress Theme

== Description ==

Rehub theme is a powerful hybrid theme designed for affiliate marketers, comparison sites, multi-vendor shops, coupon sites, review portals, and news/magazine websites.

**Key Features:**

* Multi-purpose theme for affiliate, shop, and review websites
* WooCommerce compatible with multi-vendor support
* Built-in comparison tables and price comparison tools
* Coupon and deal management functionality
* Review system with user ratings
* Elementor page builder support
* Translation ready
* RTL support
* SEO optimized

== Installation ==

1. In your WordPress admin panel, go to Appearance > Themes and click the 'Add New' button.
2. Click on 'Upload Theme' and select the rehub-theme.zip file.
3. Click 'Install Now' and then 'Activate' to activate the theme.
4. Install the required plugins when prompted.
5. Navigate to Appearance > Theme Options to configure your settings.
